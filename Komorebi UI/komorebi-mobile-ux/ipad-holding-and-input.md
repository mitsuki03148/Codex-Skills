# iPad holding and input modes

An iPad is not a larger iPhone. Width alone does not describe its ergonomics.

## Ask how the device is supported

### Two-hand held

- left thumb naturally owns a left-edge region;
- right thumb naturally owns a right-edge region;
- repeated reaches toward the center can increase thumb extension and wrist deviation;
- larger tablets can increase muscular load.

For repeated touch actions, side-edge or contextual placement can be cheaper than a visually central control.

### One-hand support + other-hand input

The interacting index finger can reach a larger area, but the supporting arm carries the device and repeated far-corner travel still has cost.

### Lap

Grip constraints reduce and reach comes more from above. The motor map becomes less like two-thumb phone use.

### Desk + pointer / hardware keyboard

Touch reach becomes less dominant. Density and keyboard/pointer affordances can increase, but touch remains a first-class input when the product supports it.

### Pencil

Precision, palm posture and occlusion change again. Toolbar placement should consider the drawing hand and the workspace rather than copying finger assumptions.

## Orientation changes biomechanics

Portrait and landscape change:

- reach;
- weight distribution;
- wrist posture;
- thumb travel;
- keyboard comfort.

Treat orientation as a physical change as well as a visual reflow.

## Edge ownership

For a tablet held with both hands, the center can be a high-cost repeated-action region.

Useful patterns can include:

- high-frequency controls near the grip edges;
- contextual controls brought toward the object;
- symmetric duplication where the action genuinely supports either hand;
- keyboard/pointer alternatives for dense work.

Do not duplicate asymmetrically or add controls merely to satisfy an edge-zone diagram.

## Platform patterns

Phone bottom navigation and iPad sidebars solve different problems. Do not copy phone ergonomics directly to tablet.

A platform convention earns weight because it combines expectation, familiarity and input behavior—not because every instance is physically optimal for every posture.
