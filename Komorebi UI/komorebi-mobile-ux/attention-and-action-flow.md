# Attention and action flow

The research supports two coupled maps rather than one universal mobile heatmap.

## Visual attention map

Where people look depends on:

- reading direction;
- task;
- semantic expectation;
- text and image content;
- familiar UI structure;
- screen region;
- visual treatment.

Research reports both top-leading bias and greater lower-screen attention under different tasks and stimuli. The useful conclusion is not which study “wins”. It is that there is **no single universal mobile eye path**.

Do not assume size or color alone controls attention. Semantic expectation and familiar placement can dominate simple saliency.

## Motor / reach map

The motor map asks:

- can the finger reach without regrip?
- how much extension and wrist movement is needed?
- is the user left- or right-handed?
- what supports the device?
- what input mode is active?
- does the finger hide the target or result?

A visually prominent control can still be motor-expensive.

## Convergence at decision points

A useful flow model is:

**ORIENT → UNDERSTAND → ACT**

which maps to the broader skill model:

**SEE → UNDERSTAND → REACH → ACT → RECOVER**

On many phone reading flows, orientation can live high, content through the middle and the repeated action lower. Treat that as a pattern to test, not a template.

## Attention/motor conflicts

### Eye high, action low

Can be healthy when the top explains and the lower region carries the next action.

### Eye and hand chase scroll content

Risk: fatigue, accidental taps and repeated reorientation.

Useful response: keep repeated actions stable or contextual rather than moving with every content shift.

### Visually central iPad action, physically far from held thumbs

Useful response: move or duplicate the frequent action toward grip-side/contextual regions when the task warrants it.

### Familiar top-corner control, hard one-handed reach

Do not automatically relocate it. Possible responses include keeping it secondary, adding a gesture, exposing a lower equivalent for the repeated action, or using row-level/contextual actions.

## What not to infer

- top-left is not always first fixation;
- bottom half is not always most attended;
- bright color does not guarantee attention;
- a visible action is not necessarily reachable;
- a reachable action is not necessarily understood.

The review question is always the whole path, not one heatmap.
