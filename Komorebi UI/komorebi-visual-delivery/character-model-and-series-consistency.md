# Character model and series consistency

A recurring character should remain recognisable across pose, expression, scene and time.

The goal is not frame tracing.

The goal is stable identity.

Use this file only when a recurring person / character / model must remain recognisably the same across outputs. Otherwise mark character consistency `N/A`.

## Character Lock

Record only anchors that are truly visible and stable in the approved references.

### 1. Head-to-body proportion

Examples:

- approximate head count;
- compact vs elongated body;
- childlike / adult-like proportion language.

Do not invent exact ratios when the source does not support them.

### 2. Silhouette

Observe:

- head shape;
- hair outline;
- shoulder width;
- torso width;
- skirt / coat / trouser mass;
- limb thickness;
- recurring negative spaces.

A black silhouette should still feel like the same character when the style depends heavily on shape.

### 3. Face shape

Observe:

- round / oval / angular;
- cheek fullness;
- jaw width;
- chin character;
- face length.

### 4. Eyes / brows / facial spacing

Observe:

- eye shape;
- eye size relative to face;
- eye spacing;
- brow angle / softness;
- vertical placement;
- mouth scale and placement.

Keep expression variation separate from identity geometry.

### 5. Hair

Observe:

- fringe shape;
- parting;
- volume;
- side locks;
- hair length;
- outer silhouette;
- recurring stray locks or tied elements.

### 6. Body build

Observe:

- shoulder-to-head relationship;
- torso length;
- waist language;
- limb thickness;
- hand / foot exaggeration;
- posture.

### 7. Clothing / accessory landmarks

Examples:

- collar;
- sleeve shape;
- belt;
- hair clip;
- bag;
- shoes;
- repeated trim;
- signature object.

Landmarks help identity survive style simplification.

### 8. Expression energy

A character can smile, cry or become surprised while retaining a stable emotional / facial language.

Avoid accidental shifts such as:

- quiet character becomes hyper-expressive cartoon;
- rounded face becomes sharp anime face;
- subtle eyes become huge glossy eyes;
- compact body becomes fashion illustration.

## Approved anchor

Choose one approved image or model sheet as the canonical anchor.

New images can add evidence, but they do not replace the anchor automatically.

## Overlay diagnostics

When pose permits:

- align head scale;
- lower opacity;
- compare face width / height;
- compare eye line;
- compare hair silhouette;
- compare shoulder width;
- compare torso proportions.

When full-body pose permits:

- compare head count;
- shoulder / hip relationship;
- limb length;
- footprint / stance.

Do not use overlay as a pass/fail metric under different camera angles.

## Pose-normalized judgement

Separate:

- identity change;
- pose change;
- foreshortening;
- perspective;
- clothing volume;
- expression.

A raised shoulder is not automatically body drift.
A wide-angle close-up is not automatically a larger head model.

## Series check

Inspect a contact sheet and compare:

- first vs latest;
- adjacent images;
- extremes of pose;
- costume variants;
- front vs three-quarter view.

Look for slow drift, not only dramatic mistakes.

## Animation

Across neighboring frames, identity should not pulse.

Watch for:

- head size wobble;
- eye spacing changing;
- face width flicker;
- hair volume breathing unintentionally;
- limb thickness changing;
- clothing landmark disappearing for one frame.

Some hand-drawn animation intentionally uses smear / squash / stretch.

When such deformation is deliberate, check whether it belongs to the approved animation language rather than banning it.
