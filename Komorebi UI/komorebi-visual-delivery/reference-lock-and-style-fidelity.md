# Reference lock and style fidelity

Reference fidelity is easier to preserve when style is decomposed before production.

Use this file only when the delivery has an authoritative reference or an approved visual language that must be preserved. Otherwise mark reference fidelity `N/A`; do not invent a style authority.

## 1. Choose the reference authority

Prefer:

1. approved canonical image;
2. approved style sheet;
3. latest approved output;
4. multiple references with explicit role labels.

Example:

- Reference A: line / shape language
- Reference B: palette
- Reference C: environment material
- Reference D: character proportions

Do not blend conflicting references silently.

## 2. Style Lock — six axes

### Line / edge language

Observe:

- thick / thin;
- uniform / variable;
- crisp / soft;
- geometric / hand-drawn;
- closed contour / implied edge;
- clean vector / textured raster;
- hard cutout / feathered or painted edge.

### Shape language

Observe:

- rounded / angular;
- compact / elongated;
- geometric / organic;
- symmetrical / irregular;
- simplified / detailed;
- exaggerated / restrained.

### Proportion language

Observe:

- head-to-body ratio;
- object exaggeration;
- limb length;
- icon / object scale;
- environmental depth;
- perspective simplification.

### Color / value language

Observe:

- warm / cool;
- saturation range;
- contrast range;
- dominant neutrals;
- accent behavior;
- shadow hue / value;
- whether color is flat, atmospheric or material-led.

### Rendering / material language

Observe:

- flat fill;
- cel shading;
- painterly;
- watercolor bleed;
- pencil grain;
- soft airbrush;
- paper texture;
- digital vector cleanliness;
- photographic / illustrative mixing.

### Composition / spacing mood

Observe:

- dense / sparse;
- centered / asymmetric;
- editorial / utility;
- cropped / contained;
- quiet negative space;
- focal mass;
- repeated shapes;
- edge tension;
- depth layering.

## 3. Must Match / Can Vary / Must Avoid

Write this before final production.

The point is not to freeze creativity.

It is to identify which freedoms are safe.

### Must Match

Traits whose loss would make the output stop belonging to the approved visual world.

### Can Vary

Pose, crop, props, expression, local background detail or other dimensions the brief allows.

### Must Avoid

Common drift directions that would produce a visibly different visual language.

Examples:

- realistic skin rendering;
- hard neon accent;
- heavy cast shadow;
- thin fashion-model proportions;
- glossy glass surface;
- noisy texture;
- overly sharp anime eye geometry.

## 4. Fidelity check

Compare output to reference by axis.

Do not ask only “similar?”

Record:

- matched;
- acceptable variation;
- drift;
- not verifiable.

A strong mismatch in one defining axis can matter more than five small matches.

## 5. Normalized comparison

When geometry matters, compare ratios rather than raw pixels.

Examples:

- head height : full body height;
- shoulder width : head width;
- eye spacing : face width;
- repeated motif size : local container;
- major color mass : whole composition.

Ratios still need interpretation under perspective and pose.

## 6. Contact sheet

For a series, inspect all outputs together.

Series-level drift often becomes obvious only side by side.

Look for gradual movement in:

- saturation;
- realism;
- line thickness;
- head size;
- body length;
- edge softness;
- material texture;
- background complexity.

## 7. Fidelity does not mean imitation without judgement

A reference can guide language without requiring literal copying of:

- pose;
- exact geometry;
- composition;
- protected creative expression.

Preserve the project's intended visual identity and the user's approved constraints.

Do not turn style matching into blind duplication when the task calls for adaptation.
